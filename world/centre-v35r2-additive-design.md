# Additive numerical integration — isolated, no promotion

This suite implements the frozen root-contract design, not a new candidate.
Original v35r2 sources, old failures and live/display images remain immutable.
The only HTML changes carry every float readback as Uint32 words, and reconstruct
the saved-point input texture from those words. The shader sources are unchanged.

## Foreground graph

`bounds → numerical → local → global → combination`

Each launcher exclusively claims a new stage directory. It records launch,
started, all durable data, result, completion, log and **actual child exit**.
Entry verifies the frozen integration, complete prerequisite inventories and
successful actual exits. Partial, signal, false-result, late-exit, tampered or
replayed attempts block downstream stages. SIGKILL cannot write a receipt; the
claimed directory still blocks replay and the absent exit blocks eligibility.

- Bounds: new destination, identical sampled calculations and inequalities.
- Numerical: 48 cases, 75,996 rays, exactly 720 independently enumerated keys.
  Original readbacks, .003 scan values, all original 24-step scan histories,
  found/missing references and original predicates/verdicts remain separate.
  Every original non-reference conjunct is transferred by AST and recomputed
  from saved metrics. Legacy cheap/full `<.00001` remains; extra gates require
  bitwise cheap/full, expanded/CSG/aperture/selected-gradient equality using saved
  Uint32 words. Raw data and legacy verdict are saved before additive assessment.
  Exit0 is non-reference readiness, **never** a forged original numerical PASS.
- Local: all 720 GPU-depth ±.004 grids, exactly 161 samples at .00005 spacing;
  all eleven expanded leaves, five base leaves, full scalar, point, tying active
  branches and source hashes. Actual GPU points/words stay separate from CPU-ray
  reconstruction. Every strict entering/exiting cell retains 24 full refinement
  transitions. Sampled/midpoint zeros fail unresolved, never select a later root.
  All profiles are saved before assessment. Saved-point CPU oracle replay checks
  every full/leaf record. Exit0 means `root_certification_ready` only.
- Global: receives no local profile or hints. The entire original from-depth0
  coarse domain, radial/envelope exclusions, Hessian enclosure, depth32 budget,
  left-first recursion and <=1e-7 strict positive/negative bracket are unchanged.
  The original results, including unresolved intervals and difference<.03, are
  saved. Complete keyed joins replace zip-based iteration, not the algorithm.
- Combination: saved GPU/scans, local records and original independent results
  join bijectively on all 720 keys. Recheck non-root/word gates, all local CPU
  oracles, strict global results, old FOUND difference<.03 and correspondence
  wholly inside exactly one original local entering cell. Joined data are saved
  before contract assessment. Missing legacy references remain visibly missing.

## Static closure

Freeze/check/close uses new one-shot foreground receipts. The static checker
reverses all derivations, compares full legacy predicate/scan and entire global
algorithm ASTs, checks independent schedules, JS syntax and exact word transport,
complete synthetic joins and all-conjunct negatives. Real foreground synthetic
children exercise success, exception, false result, partial, signal, late exit,
tamper and replay contracts. Synthetic gate overrides are labelled; no browser,
candidate field module or historical worker is run by this suite.

Only a valid close receipt plus integration manifest enables the new launchers.
No old launcher is enabled. Cost/capture successor wiring is not part of this
suite and remains blocked even if combination later passes. No root result,
performance, visual, realism, coverage, route or full acceptance credit is
granted by static closure. All held marcher/camera/control/timing/pixel-equality
limits remain those in the frozen design. No field runtime before closure.
