## A. Arithmetic microprobe; proposed isolated uniform-offset variant

Evidence: only second-offset scalar leaves fail; inverse rounding cells are
compatible with binary32 constant folding for every saved pair.

1. Freeze an input texture of at most 128 finite binary32 scalar predecessors
   per leaf. Include values from the overlapping inverse cells of saved
   mismatches, their binary32 neighbours, cancellation points and domain ends.
   Report cells containing no representable predecessor; never silently select
   favourable inputs. Hash seeds before launching. These are synthetic inputs,
   not recovered GPU intermediates.
2. In a tiny shader matching the existing precision/backend, output predecessor,
   parent and child. Constant arm reproduces the exact two nested offsets;
   variant changes ONLY the second offset from a literal to a runtime uniform
   loaded with the same binary32 value (.20 or .28). Shared input texture,
   render target and launch; record complete arms, shader/link errors and close.
3. Compare each output with separately rounded binary32 CPU operations, **exactly**.
   Also compare the child against the saved parent plus offset, exactly. Retain
   failures in both arms. No epsilon or post-readback correction. Include the
   explicit folded-constant expression as a diagnostic control, not an oracle.
   The uniform form may still be reassociated: the experiment must decide.
4. If the constant arm fails and uniform arm is exact, prepare an isolated v35
   candidate changing only these two literals to uniforms, with all uniform
   construction paths explicitly bound. Coefficients remain identical in real
   arithmetic; unchanged Hessian mathematics does NOT establish GPU equality.
   If the microprobe is inconclusive/fails, do not create a claimed fix.
5. Before any full v35 runtime, prepare/review new versioned fixtures and run
   their static checks. Future numerical acceptance must retain all 48 cases,
   75,996 rays, exact expanded/composite/normal/cheap-full equality, all original
   tolerances, budgets, fixed and independent first-root gates. Synthetic success
   does not authorize skipping actual-field expanded-jet comparisons.

Optional compiler-translated shader text may be saved if the existing WebGL
extension exposes it; absence is not a failure and no downloads/searches needed.
